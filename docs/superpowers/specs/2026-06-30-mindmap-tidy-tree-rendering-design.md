# 思维导图渲染重构设计

## 目标

把当前基于 Python Pillow 的手动思维导图渲染，替换为 **Mermaid `tidy-tree` 布局渲染**，同时保留按章节自动拆图、Markdown/Word 多图引用、以及校验失败 fallback 机制。解决现有实现中的文本截断、节点重叠、布局僵硬问题。

## 架构

```
.mmd 文件
   │
   ▼
┌─────────────────────────────────────┐
│  MermaidMindmapRenderer             │
│  - 添加 tidy-tree 配置 frontmatter  │
│  - 为 1 级章节添加序号              │
│  - 按章节拆分为多个子 .mmd          │
└─────────────────────────────────────┘
   │
   ▼
┌─────────────────────────────────────┐
│  mmdc (Mermaid CLI)                 │
│  - 渲染每个子 .mmd 为 PNG           │
└─────────────────────────────────────┘
   │
   ▼
┌─────────────────────────────────────┐
│  LayoutVerifier                     │
│  - 规则检查：尺寸、节点数、截断     │
└─────────────────────────────────────┘
```

## 关键设计决策

### 1. 渲染后端：Mermaid `tidy-tree`

- 在 `.mmd` 文件开头注入 YAML frontmatter：
  ```yaml
  ---
  config:
    layout: tidy-tree
  ---
  ```
- 使用系统安装的 `mmdc`（Mermaid CLI）渲染 PNG
- 通过 `PUPPETEER_EXECUTABLE_PATH` 环境变量指向系统 Chrome，避免 mmdc 找不到浏览器

### 2. 1 级标题加章节序号

生成 `.mmd` 时，把顶层章节节点从：
```
基础概念
```
改为：
```
1. 基础概念
```

序号按原始章节顺序生成，从 1 开始。

### 3. 拆图策略

- 当单图节点数或预估高度超过阈值时，按 1 级章节拆分为多个子 `.mmd`
- 每个子图保留根节点（视频标题），但只包含部分章节
- 每张图至少包含 2 个章节或至少 N 个节点，避免过稀疏的子图
- 拆分后的子图文件名使用 `mindmap_01.png`、`mindmap_02.png` 等序号

### 4. 布局校验

渲染后执行自动校验：

| 检查项 | 规则 |
|--------|------|
| 单图尺寸 | 宽度 ≤ 3000px，高度 ≤ 3000px |
| 节点数 | 单图节点数 ≤ 80 |
| 文本截断 | 检查 PNG 中是否出现大量 "…" 或不完整文字 |
| 节点重叠 | 通过 OCR/像素分析检测节点区域是否重叠 |

校验实现分两层：
- **规则层**：先用本地脚本快速检查尺寸、节点数、简单 OCR
- **视觉模型层**（可选）：规则层发现可疑问题或配置启用时，调用多模态模型复核

### 5. Fallback 策略

- 当校验未通过时，自动切换为 Mermaid 默认径向布局（`mindmap` 不加 `tidy-tree` 配置）重新渲染
- Fallback 结果仍然执行校验，如果仍失败则记录警告并继续，不阻塞整体流程

### 6. Markdown/Word 更新

- 保持现有的 `mindmap_image_paths: list[Path]` 结构
- Markdown 中插入所有子图，格式为 `![思维导图](mindmap_01.png)`
- 每次更新时先清除旧的思维导图章节和图片引用，避免重复

## 组件

### `MermaidMindmapRenderer`

负责：
- 读取原始 `.mmd`
- 注入 `tidy-tree` frontmatter
- 为 1 级章节添加序号
- 按章节拆分子 `.mmd`
- 调用 `mmdc` 渲染 PNG
- 返回 PNG 路径列表

### `LayoutVerifier`

负责：
- 检查 PNG 尺寸
- 检查节点数
- OCR 检查文本截断
- 返回问题列表

### `MindmapFallback`

负责：
- 当主渲染校验失败时，用 Mermaid 默认径向布局重新渲染

## 验收标准

1. 单图宽度 ≤ 3000px，高度 ≤ 3000px
2. 节点之间不重叠
3. 文字不被截断（不出现明显 "…" 或不完整文字）
4. 1 级章节标题带序号，如 "1. 基础概念"
5. 少量章节时纵向树状布局；分支增多后自动横向展开；过多时自动拆成多张图
6. 每张拆分的子图至少有 2 个章节或至少 10 个节点，避免稀疏子图
7. Markdown 和 Word 正确引用所有子图
8. 校验失败时自动 fallback 到径向布局
9. 所有现有 mindmap 相关测试通过
10. 新增至少 3 个测试：tidy-tree 渲染、章节序号、拆图最小内容量

## 测试策略

1. **单元测试**
   - `_add_chapter_numbers()` 正确添加序号
   - `_split_by_chapters()` 遵守最小内容量阈值
   - `_inject_tidy_tree_config()` 正确注入 frontmatter

2. **集成测试**
   - 用真实 `.mmd` 调用 `MermaidMindmapRenderer.render()`，验证输出 PNG 数量和尺寸
   - 验证校验器能识别故意制造的截断/重叠

3. **回归测试**
   - 确保 Markdown/Word 多图引用不被破坏
   - 确保 `--mermaid` 参数行为保持一致

## 不做什么

- 不重新实现一个完整的树状布局算法
- 不修改 Mermaid 库本身
- 不调用视觉模型或云端多模态 API 做校验
- 不再保留 Python Pillow 手动渲染路径作为可选方案
