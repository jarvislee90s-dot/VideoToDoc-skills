# [学习工作] VideoToDoc — 视频一键变图文讲义,把 1 小时课程沉淀成可搜索的团队知识

## 创意名称 + 创意介绍

**创意名称:** VideoToDoc

**想解决什么问题:** 看培训课、技术分享、行业报告这类长视频,真正能记住并能检索的不到 10%;1 小时视频要花 2-3 小时手动做笔记,做完后又找不到具体内容;团队培训内容散落在个人收藏夹,无法沉淀共享。

**为什么会想到做这个:** 作为开发者,每次看 AI/技术分享视频(会议录像、技术大会、英文讲座)都要在本地建笔记、写摘要、截关键画面,流程重复且低效。调研后没找到合适的端到端方案——多数工具只做 ASR 转录,不做图文对齐;少数做讲义的又是 SaaS 且收费,数据还得出本机。所以我决定把"下载→转录→截图→对齐→整理→发布"做成一套本地 CLI 工作流。

**大概是什么产品:** 一套本地 CLI 工具链(三个 Skill)+ 飞书云文档输出;Apple Silicon 优化、免费、MIT 协议开源,数据全程不出本机。

## 目标用户及痛点

**面向哪些用户:**

- 培训学员 / 在校学生 — 看完网课需要做系统化笔记
- 知识工作者 / 工程师 — 看英文技术大会、行业分享需要二次消化
- 团队学习负责人 / 内训师 — 每周要给团队同步外部课程要点
- 播客主理人 / 视频创作者 — 把长访谈转成可阅读的图文稿

**在什么场景下使用:**

- 看完 1 小时长视频后,想沉淀成可搜索的结构化笔记
- 团队每周技术分享会,需要把外部大咖分享转成可分发材料
- 培训部门需要把外部课程内容沉淀进企业知识库(飞书/Notion)
- 自己做长期学习的"复盘卡片",按主题归档

**当前痛点:**

- **手动记笔记效率低** — 1 小时视频要花 2-3 小时,且容易遗漏关键帧
- **视频内容不可检索** — 视频文件不支持全文搜索,只能拖进度条回忆
- **团队知识不沉淀** — 个人笔记锁在 Notion/语雀,跨团队无法共享
- **现有工具不闭环** — Whisper 只能转录、GPT 只能总结、剪映只能剪辑,没人把"视频→讲义→发布"串起来

## 价值与意义

**效率提升(主要):**

- **10x 加速** — 1 小时视频从 2-3 小时笔记压缩到 5-10 分钟自动出稿
- **图文对齐精度 100%** — 毫秒级时间戳匹配,关键截图不漏不错
- **批量可执行** — CLI 工具,可脚本化、可 CI、可批量处理历史视频
- **跨语言支持** — 中英双语,英文视频直接生成中文讲义(可配置)

**商业/团队价值:**

- **从个人工具变团队资产** — 自动同步到飞书云文档,带评论/权限/版本控制
- **零运营成本** — 本地运行,无需服务器、无 API 费用、无月费
- **可私有部署** — 企业内网部署,合规友好

**社会价值:**

- **降低学习门槛** — 残障人士(听障)、非母语学习者(读字幕比听更高效)受益
- **知识平权** — MIT 协议开源,所有教学资源都能零成本转讲义
- **减少 AI 焦虑** — 把"AI 时代要学的内容"可视化、可消化
