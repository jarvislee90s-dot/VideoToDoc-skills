VideoToDoc Agent Demo

把一个视频链接交给 Agent，自动完成摘要、讲义、飞书发布。

Agent 配置
三个 Skill
video-summary — 视频转录与摘要

输入视频链接或本地路径，自动获取字幕或 ASR 转录，生成文字摘要。

video-to-slides — 截图与图文讲义

自动截图去重、图文对齐、语义整理，输出 Markdown/Word 与思维导图。

feishu-markdown-publish — 飞书云文档发布

将整理好的 Markdown 讲义发布到飞书云文档。
