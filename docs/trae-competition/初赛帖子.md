## 1. Demo 简介

### 是什么

VideoToDoc 是一套**本地 CLI 工具链**，能把任意视频（B站/YouTube/本地文件）一键转成图文讲义。输入视频 URL，自动完成：下载 → 字幕/ASR 转录 → 截图去重 → 图文对齐 → 语义整理 → 生成 Markdown/Word/思维导图 → 发布飞书云文档。

### 面向谁

- **培训学员 / 在校学生** — 看完网课需要系统化笔记
- **知识工作者 / 工程师** — 看英文技术大会、行业分享需要二次消化
- **团队学习负责人 / 内训师** — 每周要给团队同步外部课程要点
- **播客主理人 / 视频创作者** — 把长访谈转成可阅读的图文稿

### 主要功能

| 功能 | 说明 |
|------|------|
| 视频转文字 | URL/本地视频 → 字幕优先获取 → mlx-whisper ASR fallback → 带时间戳 transcript |
| 截图去重对齐 | 三段式去重（明显重复合并/明显不同保留/不确定 OCR 判定）+ 毫秒级图文对齐 |
| 语义整理 | Agent 改写口播为书面语，自动补全主语、去填充词、分章节加目录 |
| 多格式输出 | Markdown 讲义 + Word 文档 + Mermaid 思维导图（PNG） |
| 飞书发布 | 逐页上传飞书云文档，带图片/分隔线/思维导图附件 |

## 2. Demo 创作思路

### 灵感来源

作为开发者，每次看 AI/技术分享视频（会议录像、技术大会、英文讲座）都要在本地建笔记、写摘要、截关键画面，流程重复且低效。调研后没找到合适的端到端方案——多数工具只做 ASR 转录，不做图文对齐；少数做讲义的又是 SaaS 且收费，数据还得出本机。

### 想解决的问题

1. **手动记笔记效率低** — 1 小时视频要花 2-3 小时手动记录，还容易遗漏关键帧
2. **视频内容不可检索** — 视频文件不支持全文搜索，只能拖进度条回忆
3. **团队知识不沉淀** — 个人笔记锁在 Notion/语雀，跨团队无法共享
4. **现有工具不闭环** — Whisper 只能转录、GPT 只能总结、剪映只能剪辑，没人把"视频→讲义→发布"串起来

### 为什么做这个方向

- 培训视频看完就忘，真正能记住并能检索的不到 10%
- 1 小时视频要花 2-3 小时手动做笔记，做完后又找不到具体内容
- 团队培训内容散落在个人收藏夹，无法沉淀共享

## 5. 技术亮点

### 本地优先，数据不出机

- Apple Silicon 优化（mlx-whisper），免费、MIT 协议开源
- 无需服务器、无 API 费用、无月费

### 三段式截图去重

1. **明显重复** → 合并（哈希相似度 > 阈值）
2. **明显不同** → 保留
3. **不确定** → OCR 判定（提取文字对比）

### 毫秒级图文对齐

- 基于时间戳的精确对齐，关键截图不漏不错
- 自动 drift forward 处理纯黑屏/过渡帧

### 结构形态自适应

- 支持 4 种视频类型原型：`topic_preserve`（资讯/访谈）、`enumeration_unit`（教程/盘点）、`visual_event`（PPT讲解）、`rescan_grid`（多产品对比）
- Agent 自动判定类型，选择最优分段策略

## 7. 开始用

```bash
# 1. Clone 项目
git clone https://github.com/jarvislee90s-dot/VideoToDoc-skills.git
cd VideoToDoc-skills

# 2. 安装依赖
pip install mlx-whisper python-docx Pillow curl_cffi yt-dlp opencv-python numpy rapidocr
npm install -g @mermaid-js/mermaid-cli

# 3. 三步跑通
python3 .agents/skills/video-summary/scripts/process.py "视频URL"
python3 .agents/skills/video-to-slides/scripts/process.py video.mp4 --transcript transcript.json
python3 .agents/skills/feishu-markdown-publish/scripts/publish.py 讲义.md
```
